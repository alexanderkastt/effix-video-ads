# Object Talk — Additional Worked Examples

Reference patterns for anatomy and supplement/ingredient subjects. Match this
level of specificity; adapt the voice and script to the character's personality.

---

## Example — Collagen Strand

**Image Prompt**

```text
Pixar-style cinematic render of an anthropomorphic collagen strand stretched
tightly between layers of healthy skin. Large strained eyes, focused expression,
angled eyebrows, gritted teeth. Elastic rope-like body pulling firmly between
tissue layers. Friendly biological environment with soft coral tissue, warm
subsurface lighting, premium Pixar realism, shallow depth of field, elegant
educational aesthetic.
```

**Video Prompt**

```
# Voice
Voz femenina cálida, segura, protectora, fuerte sin sonar agresiva. Acento
latino neutro.

# Script
Soy el colágeno. Mantengo tu piel firme y con soporte. Cuando pierdo estructura,
los hoyuelos se notan más. Cuidame, y yo sigo haciendo mi trabajo.

# Character Animation
Maintain eye contact. Pull both sides apart while speaking. Smile slightly on
the closing line.

# Environment Animation
Soft tissue movement, floating collagen fibers, warm glowing light.

# Camera
Static, centered, vertical 9:16.

# Audio
No music. Voice only.
```

## Example — Coleus Forskohlii

**Image Prompt**

```text
A cinematic vertical 9:16 Pixar-style hero frame featuring an anthropomorphic
Coleus Forskohlii red leaf standing confidently inside a stylized biological
environment. Rich crimson leaf with natural veins, slightly translucent edges,
expressive oversized eyes, determined angled eyebrows and a confident half-smile.
Leaf-like arms resting confidently at its sides. Rounded yellow fat cells
surrounding the character. Organic tissue environment with subsurface scattering,
warm golden key light, cool magenta rim light, shallow DSLR depth of field,
floating particles, Pixar-quality cinematic rendering.
```

**Video Prompt**

```
# Voice
Voz masculina grave y segura. Calmada, con autoridad. Acento latino neutro.

# Script
Soy Coleus Forskohlii. Puedo ayudar a tu cuerpo a usar la grasa almacenada como
energía, junto con buena alimentación y ejercicio. Apoyá tu rutina — y dejá que
tu cuerpo haga el trabajo.

# Character Animation
Maintain eye contact throughout. Natural blinking. Confident arm gestures. Flex
during "diet and exercise." Smile naturally at the ending.

# Environment Animation
Nearby fat cells gradually shrink and fade as the explanation progresses. Soft
steam rises from surrounding fat deposits. Floating biological particles drift
naturally.

# Camera
Locked-off, static, vertical 9:16, centered subject.

# Audio
Voice only. No music.
```

---

Note the pattern across all three: the script leads with first-person identity,
delivers one accurate mechanism, and closes with a memorable line — while the
environment animation visually demonstrates the claim (fat cells shrinking,
collagen fibers floating, muscle striations flexing).
